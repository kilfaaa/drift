# Сайт coffeeGaysClub · Medvedovka

Открытая часть: название спота и таймер до ближайшего дождя.
Закрытая часть (вердикт, сборы, прогноз на 14 вечеров, экипаж) открывается только по личному коду.

## Как устроено

- Сборы, карточки и фото лежат в `crew/vault.json` в зашифрованном виде (AES-256-GCM). Без кода там нечитаемый набор символов.
- У каждого человека свой код. Код один раз вводится на сайте, и телефон его запоминает. Кнопка «Выйти» сверху стирает код.
- Список кодов зашифрован в `crew/admin.json` кодом администратора.
- Открытых данных в репозитории нет.

## Как что-то поменять

Проще всего попросить Claude: «объяви сбор…», «добавь дрифтера…», «дай код новому человеку», «забери доступ у…». Для этого понадобится код администратора.

Вручную (нужен Python 3 и пакет cryptography):

```
python3 tools/crew.py unlock --code АДМИН-КОД      # расшифровать в папку plain/
# поправить plain/data.json, положить фото в plain/photos/
python3 tools/crew.py seal   --code АДМИН-КОД      # зашифровать обратно
python3 tools/crew.py add    --code АДМИН-КОД --name "Имя"   # новый код
python3 tools/crew.py revoke --code АДМИН-КОД --name "Имя"   # забрать доступ
```

Папка `plain/` в git не попадает. Никогда не загружай её содержимое в репозиторий вручную.
