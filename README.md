## Что делает сайт

Сайт отвечает на один вопрос: **будет ли асфальт на заданной точке мокрым в заданное окно времени** (сейчас 20:00–00:00) сегодня и в ближайшие 14 дней. Мокрым считается асфальт, на который дождь шёл во время окна или незадолго до него и ещё не успел высохнуть.

## Что на сайте

| Без кода | С личным кодом |
|---|---|
| Название спота и таймер **ДД:ЧЧ:ММ:СС** до ближайшего дождя | Вердикт на сегодняшний вечер: «Мокро. Едем» / «Может быть» / «Сухо» |
| | Ближайший сбор: дата, время, заметка, маршрут |
| | Дрифтовый прогноз на 14 вечеров с шансом мокрого асфальта в % |
| | Экипаж: карточки дрифтеров с фото и характеристиками машин |
| | Координаты точки и маршрут |

## Как считается прогноз

Сайт сам, прямо в браузере, скачивает прогноз по координатам точки из бесплатного API [Open-Meteo](https://open-meteo.com/). Сервер и ключи не нужны.

1. **Восемь погодных моделей.** Это общий прогноз Open-Meteo плюс ECMWF, ECMWF AIFS (нейросетевая), ICON, ICON-EU, GFS, UKMO и GEM. Каждая грузится отдельным запросом, так что сбой одной модели не ломает остальные.
2. **Четыре ансамбля** (ECMWF, GFS, ICON, GEM), всего 100+ расчётов. Доля расчётов, где вечер получается мокрым, и есть честная вероятность.
3. **Баланс воды на асфальте.** Дождь добавляет воду (до 0,8 мм плёнки), испарение из прогноза (ET₀: температура, ветер, влажность, солнце) её убирает. Асфальт мокрый, если плёнка ≥ 0,1 мм или идёт дождь ≥ 0,1 мм/ч.
4. **Вечер мокрый,** если вода держится хотя бы 2 часа из окна 20:00–00:00.
5. **Итоговый шанс** = 65% ансамбль + 35% обычные модели. «Едем» — от 60%, «Может быть» — от 30%.
6. **Таймер в шапке** показывает ближайший час, когда дождь вероятнее, чем нет (от 50%).

Ещё сайт предупреждает о гололёде (до +1 °C) и сильном ветре (от 12 м/с). Дальше пяти дней прогноз осадков заметно менее точный, такие строки показаны бледнее.

## Закрытая часть и коды

GitHub Pages умеет только публичные сайты, поэтому приватные данные **зашифрованы**:

- сборы, карточки и фото лежат в [`crew/vault.json`](crew/vault.json), зашифрованные AES-256-GCM;
- общий ключ данных обёрнут отдельно для каждого участника его личным кодом (PBKDF2-SHA256, 250 000 итераций);
- браузер расшифровывает данные через WebCrypto, код запоминается на устройстве, кнопка «Выйти» его стирает;
- список кодов лежит в [`crew/admin.json`](crew/admin.json) и зашифрован кодом администратора;
- **открытых данных в репозитории нет**, рабочая копия `plain/` в git не попадает.

Если забрать доступ у одного человека, ключ данных меняется, а коды остальных продолжают работать.

## Управление

Нужен Python 3 и пакет `cryptography` (`pip install cryptography`).

```bash
python3 tools/crew.py unlock --code АДМИН-КОД                  # расшифровать в plain/
# правим plain/data.json, фото кладём в plain/photos/
python3 tools/crew.py seal   --code АДМИН-КОД                  # зашифровать обратно

python3 tools/crew.py add    --code АДМИН-КОД --name "Имя"     # выдать новый код
python3 tools/crew.py revoke --code АДМИН-КОД --name "Имя"     # забрать доступ
python3 tools/crew.py list   --code АДМИН-КОД                  # у кого есть доступ
```

## Структура

```
index.html        весь сайт: разметка, стили, прогноз, расшифровка
crew/vault.json   зашифрованные сборы, карточки и фото
crew/admin.json   зашифрованный список кодов
tools/crew.py     шифрование, выдача и отзыв кодов
photos/spot.jpg   фото точки для шапки
docs/banner.jpg   баннер для README
```

Сборки нет: GitHub Pages отдаёт файлы как есть. Посмотреть локально:

```bash
python3 -m http.server 8000   # и открыть http://localhost:8000
```
